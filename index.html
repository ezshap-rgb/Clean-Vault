Deployment & Setup Walkthrough
Step 1: Deploy Backend Script
Go to script.google.com, create a New Project called Clean Vault Backend, and paste the code from Code.gs.
Click Deploy > New deployment > Web app. Set Execute as: Me and Who has access: Anyone. Copy the /exec URL.
Step 2: Get your Gemini Key
Create a key at aistudio.google.com and paste it above.
Step 3: Install to Phone Home Screen
In Safari (iOS) tap Share > Add to Home Screen. In Chrome (Android) tap Options (⋮) > Install app / Add to Home screen.
